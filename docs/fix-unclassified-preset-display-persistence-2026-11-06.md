# 미분류 소설 예약 저장 폴더명 표시 지속성 및 우선 선택 개선 보고서

- **작업 일자**: 2026-11-06
- **관련 파일**:
  - `server/static/admin/admin-drawer.js`
  - `server/static/admin.css`
  - `server/templates/admin.html`

---

## 1. 개요 및 배경
- 사용자가 미분류 보관함에서 소설 폴더명을 예약 저장한 뒤 웹 캐시를 지우거나 새로고침했을 때, 저장된 내용이 화면에서 사라진 것처럼 보이는 현상 발생.
- **원인 분석**:
  1. 실제 데이터베이스(`novel_works.custom_folder_name`)에는 예약 폴더명이 안전하게 영구 저장되어 있었음 (실제 DB 조회 결과 확인: `kakuyomu:16817139555137910443` -> `'찐따인 내가 S급미녀들의 이상형인 건에 대하여'`).
  2. 그러나 새로고침 시 무조건 단락 수가 가장 많은 0번 소설(`kakuyomu:1177354054889384502`, 10,853단락)이 자동 선택되어 우측 상세창에 표시되었고, 예약 저장했던 소설(2,415단락)은 선택되지 않음.
  3. 좌측 Master 소설 카드 목록에서도 메인 제목이 여전히 일본어 원제로만 표시되어 있어, 저장한 한국어 폴더명이 목록에서 눈에 띄지 않아 데이터가 유실된 것으로 오인됨.

---

## 2. 해결 및 UI/UX 개선

1. **예약 저장 소설 최상단 우선 정렬 ([`admin-drawer.js`](file:///c:/LANOVEL/server/static/admin/admin-drawer.js))**:
   - `custom_folder_name`이 존재하는 소설을 목록 최상단에 우선 정렬하여, 예약한 소설이 단락 수에 밀려 숨겨지지 않도록 개선.
2. **소설 카드 메인 제목을 예약된 폴더명으로 전환**:
   - 예약된 폴더명이 있을 경우 카드의 메인 제목을 `🔖 [예약된 폴더명]`(황금빛 강조)으로 표시하고, 기존 일본어 원제는 하단 서브 텍스트(`card-sub-title`)로 친절하게 안내.
3. **선택 상태 영구 기억 및 우선 선택**:
   - `localStorage`에 최근 선택한 소설 ID(`lanovel:last-unclassified-work-id`)를 보존하여, 새로고침이나 캐시 삭제 후에도 작업 중이던 소설이 즉시 자동 선택되도록 구현.
   - 마지막 선택 정보가 없더라도 예약 저장된 소설이 1순위로 자동 선택됨.
4. **JS 번들 캐시 무효화 ([`admin.html`](file:///c:/LANOVEL/server/templates/admin.html))**:
   - `admin-main.js?v=4.8`로 버전을 판올림하여 브라우저 모듈 캐시 갱신 보장.

---

## 3. 검증 결과
- 새로고침 및 캐시 삭제 후에도 예약 저장된 소설(`찐따인 내가 S급미녀들의 이상형인 건에 대하여`)이 목록 최상단에 황금빛 제목으로 노출되고, 우측 패널에 즉시 등록 버튼과 함께 완벽하게 유지됨을 확인.
