# GEMINI.md 작업 원칙 및 코드베이스 레퍼런스 관리 규칙 갱신 (2026-09-19)

### 주요 수정사항

*   `GEMINI.md` 작업 지침에 **[작업 원칙 및 코드베이스 레퍼런스 관리]** 섹션을 추가했습니다.
*   **사전 레퍼런스 필수 숙지**: 모든 질문 응답 및 작업 시작 전 반드시 `docs/codebase-functional-reference-YYYY-MM-DD.md` 최신 버전을 먼저 읽도록 지침을 명시했습니다.
*   **실시간 레퍼런스 갱신**: 작업 진행 중 새롭게 알게 된 로직, 추가/수정된 함수 및 API 명세를 실시간으로 레퍼런스 문서에 누적 기록하도록 했습니다.
*   **작업 마무리 및 버전 관리**: 작업 완료 시 레퍼런스 문서를 최종 정리하고 작업일자(`YYYY-MM-DD`) 또는 버전 접미사(예: `-2`)로 파일명을 갱신하도록 워크플로우를 체계화했습니다.

---

### 배경 및 목적

1. **지속 가능한 컨텍스트 보존**:
   - 세션이 바뀌거나 새로운 대화가 시작되어도 AI가 `codebase-functional-reference-YYYY-MM-DD.md`를 최우선으로 읽음으로써 프로젝트의 전체 세부 함수, 아키텍처, 사용자 발화 매핑 사전을 즉시 복원할 수 있도록 보장합니다.
2. **코드 변경과 레퍼런스의 동기화**:
   - 코드가 수정될 때마다 개별 변경 문서(`docs/[기능]-[날짜].md`)뿐 아니라 통합 레퍼런스 문서도 함께 갱신되어 문서와 코드의 불일치(Drift)를 방지합니다.
