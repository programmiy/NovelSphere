# UI/UX 관찰 사항 및 차세대 시스템 개선 로드맵 보고서 (2026-09-19 개정)

## 1. 개요
본 문서는 LANOVEL 시스템의 최근 구현 현황(확장 프로그램 재검수 타겟 강조 패널, Flash Lite 프롬프트 고도화 등)을 사용자의 실제 검증 결과를 바탕으로 재점검하고, 사용자의 상세 피드백을 반영하여 실현 가능성과 실사용 가치가 극대화된 **차세대 5대 로드맵 개정안**을 정리한 종합 보고서입니다.

### [Phase 1] 확장 프로그램 중심 수동 자가치유 워크플로우 고도화
* **방향성**:
  - 현재 Flash Lite 프롬프트가 충분히 안정적으로 동작하고 있으므로, 고비용 AI 자동 재번역 파이프라인을 무리하게 도입하기보다 **방금 검증 완료된 브라우저 확장 프로그램 재검수 패널(`#review-target-panel`)을 핵심 수동 자가치유 도구로 발전**.
* **상세 구성**:
  1. **검수 타겟 인라인 퀵 에디트**:
     - 재검수 패널의 카드에서 바로 번역문을 직접 수정하거나 올바른 단어를 주입할 수 있는 인라인 입력 폼 연동.
  2. **유사 표현 원클릭 치환 추천**:
     - 삭제/재검수 대상 문장의 일본어 키워드에 대해 기존 DB의 유사 번역 성공 사례를 팝오버로 띄워 클릭 한 번으로 올바른 번역 적용.
  3. **검수 완료 상태 동기화**:
     - 사용자가 수동 수정을 마치면 즉시 DB에 정상 번역으로 승격 저장되고, 알림 센터 카운트가 실시간 차감.

### [Phase 2] 서재 완결작 전용: 스포일러 방지 사전 생성형 용어집 (Progressive Glossary Engine)
* **방향성**:
  - 관리 페이지가 아닌 **서재(Library) 페이지에서 책을 클릭하여 '완결' 표시를 지정한 작품에 한해서만** 본 기능을 가동.
  - 런타임 AI 호출로 인한 리소스 낭비를 막고, 독자의 감상을 해치는 **스포일러를 원천 차단**하는 점진적(Progressive) 용어집 설계.
* **상세 구성**:
  1. **서재 페이지 완결 토글 UI**:
     - 서재의 소설 카드 상세 모달에 `[✓ 완결 작품]` 토글 버튼 신설. 완결 상태로 활성화된 소설에 대해서만 백그라운드 용어집 빌더 가동.
  2. **룰베이스 고유명사 추출 + AI 회차별 DB 순회 사전 구축**:
     - 1단계: 룰베이스(MeCab/정규식 형태소)로 소설 전체에서 빈발 출현하는 인명/지명/고유명사 후보군 일괄 추출.
     - 2단계: AI가 1회성으로 회차 DB를 순회하며 각 회차별 등장 정보 및 캐릭터 관계를 파악하여 DB에 사전 적재(`NovelGlossaryProgression`).
  3. **스포일러 방지 필터링 (회차 진행도 비례 노출)**:
     - 독자가 N화를 읽고 있을 때는 **N화 이전(1화 ~ N-1화)에서만 습득할 수 있었던 정보만 필터링하여 프롬프트/UI에 제공**.
     - 후반부의 반전(예: 정체, 흑막, 사망 등) 정보가 초중반 번역이나 툴팁에 유출되는 현상을 완벽하게 차단.
  4. **AI 리소스 절약 (Pre-computed Zero-Cost Retrieval)**:
     - 실시간 번역 시 매번 AI를 호출하지 않고, **이미 DB에 저장된 사전 분석 결과만 즉시 조회(Output only pre-stored data)**하여 지연 시간 0ms 및 API 비용 0원으로 운영.

### [Phase 3] 관리자 팝업창 및 모달 미려한 모던 UI 리뉴얼
* **방향성**:
  - 현재 크기가 너무 작고 디자인이 촌스러운 관리자 팝업창(알림 센터 팝업, 상세 모달 등)을 넉넉하고 시각적으로 세련된 모던 UI로 전면 탈바꿈.
* **상세 구성**:
  1. **충분한 크기와 쾌적한 뷰포트 확보**:
     - 답답하게 좁았던 팝업 너비와 최대 높이를 대폭 확장하여, 긴 원문과 번역문, 메타 정보가 한눈에 들어오도록 개선.
  2. **현대적인 비주얼 스타일 (Glassmorphism & Clean Dark)**:
     - 은은한 반투명 블러 백드롭, 미려한 곡률(Border-radius), 세련된 박스 섀도우 및 포인트 컬러(Cyan/Indigo) 적용.
     - 가독성 높은 폰트 위계와 태그 배지 디자인 정돈.
  3. **유연한 확장성**:
     - 팝업 내부의 세부 기능(휴지통 복구 등)은 추후 사용 패턴에 맞춰 단계적으로 추가할 수 있도록 모듈형 카드 구조로 레이아웃 설계.

### [Phase 4] 브라우저 확장 프로그램 미려한 디자인 개편 & 스마트 키보드 내비게이션
* **방향성**:
  - 방금 구축된 하이라이트 및 재검수 패널의 비주얼을 확장 프로그램 전반으로 확대 적용하고, 소설 사이트 감상 및 검수를 마우스 없이 키보드만으로 끝낼 수 있는 강력한 내비게이션 구축.
* **상세 구성**:
  1. **확장 프로그램 UI 미려한 비주얼 업그레이드**:
     - 사이드바와 플로팅 패널의 폰트, 간격, 컬러 팔레트를 미려하게 다듬어 독서 몰입감을 극대화.
     - 현재 재검수 타겟 하이라이트 스타일과 자연스럽게 어우러지는 현대적이고 고급스러운 디자인 룩앤필 확립.
  2. **소설 사이트별 이전화 / 다음화 / 목차 이동 단축키**:
     - 소설 사이트(소설가가 되자, 카쿠요무, 하멜른 등)의 페이지 구조를 자동 감지.
     - `[` 또는 `H`: 이전 화 이동
     - `]` 또는 `L`: 다음 화 이동
     - `O` 또는 `T`: 소설 목차(TOC) 페이지로 이동
  3. **소설 목차(TOC) 키보드 다이렉트 점프**:
     - 목차 페이지에서 숫자 키패드나 검색어 입력창을 즉시 띄워 원하는 회차 번호 입력 시 해당 위치로 즉시 스크롤 및 엔터로 진입.

### [Phase 5] 알림 센터 재번역 대상 단일 탭 순차 자동 처리 파이프라인 (Single-Tab Sequential Runner)
* **방향성**:
  - 새 창이나 여러 탭이 중구난방으로 열려 브라우저가 느려지는 현상을 배제하고, **하나의 전용 탭 안에서 알림 센터의 재번역 필요 페이지들을 순차적으로 방문하여 번역 ➔ API 초기화 ➔ 다음 페이지 이동을 자동으로 완료**하는 견고한 자동화 시스템.
* **상세 구성**:
  1. **단일 탭(Single Tab) 오케스트레이션**:
     - 알림 센터의 `[일괄 순차 재번역 시작]` 트리거 시 단 1개의 작업 탭만 생성(또는 현재 탭 재활용).
  2. **페이지별 재검수 번역 및 대기**:
     - 첫 번째 대상 에피소드 페이지로 이동 ➔ 재검수 요청 상태로 자동 번역 수행 ➔ 번역 완료 및 검수 상태 갱신 확인.
  3. **세션/API 초기화 및 다음 회차 전환**:
     - 한 페이지 처리가 끝나면 모델 세션 쿠키 초기화 주기(`_gemini_session.cookies.clear()`)에 맞춰 안전하게 대기(Cool-down) 후, 다음 재번역 대상 페이지 URL로 동일 탭 내에서 순차 전환.
  4. **알림 센터 실시간 완료 동기화**:
     - 순회가 진행됨에 따라 알림 센터의 미처리 항목이 하나씩 실시간으로 클리어되며, 모든 순회가 완료되면 최종 완료 토스트 안내.
