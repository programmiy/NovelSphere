# 전체 선택 시 브라우저 프리징 지연(Lag) 개선 (2026-06-05)

## 1. 개선 배경
* 웹 번역관리 페이지 및 크롬 익스텐션 히스토리 페이지에서 "폴더 전체 선택" 체크박스를 클릭할 때, 하위 데이터량이 많을 경우 브라우저가 수 초간 일시적으로 멈추는(프리징) 현상이 있었습니다.

## 2. 원인 분석
* 기존 코드의 `handleCheckboxChange` 함수는 폴더 하위의 개별 그룹 체크박스들을 순회하며 `cb.click()` 메서드를 인위적으로 호출하여 가상 이벤트를 지속해서 발생시켰습니다.
* 이로 인해 매 루프마다 브라우저가 다량의 클릭 이벤트를 중복 처리하고, 레이아웃 변경 함수(`updateBulkActionPanel()`)를 무의미하게 반복 호출(reflow 발생)하여 심각한 렉 현상이 유발되었습니다.

## 3. 해결 조치
* 이벤트 트리거를 유발하는 `cb.click()` 호출을 전면 제거하고, 모든 체크박스의 `checked` 상태 어트리뷰트만 직접 변경(`cb.checked = target.checked`)하도록 최적화했습니다.
* [admin.js](file:///C:/LANOVEL/server/static/admin.js#L567-L582) 및 [history.js](file:///C:/LANOVEL/extension/history.js#L363-L380) 소스 코드를 개선하였습니다.
* 이를 통해 하위 체크박스들의 일괄 선택 기능은 100% 동일하게 유지되면서, 이벤트 루프 중첩 및 reflow 횟수가 단 1회로 감소하여 대량의 데이터가 선택되는 상황에서도 프리징 현상이 완전히 해결되었습니다.
