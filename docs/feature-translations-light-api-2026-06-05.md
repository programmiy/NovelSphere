# 폴더별 번역 기록 조회 API 경량화 옵션 추가 (2026-06-05)

## 1. 개요
* `DB_성능_개선_및_뷰어_지연_해결_계획.md`에 기재된 `[작업 2] 목록 조회 API 경량화`를 구현하되, 원문 및 번역문 텍스트가 화면 렌더링에 필수적인 기존 웹 UI/익스텐션 코드와의 하위 호환성을 지키기 위해 조건부 경량화 옵션을 도입했습니다.

## 2. 변경 사항
* [data_crud.py](file:///C:/LANOVEL/server/routers/data_crud.py#L264-L290)의 `/translations_by_folder` 엔드포인트에 `light: bool = False` 쿼리 파라미터를 추가했습니다.
* **`light=True` 인자 적용 시:**
  * 데이터베이스에서 본문(`original`, `translated`) 필드를 쿼리에서 배제하여 OORM 메모리 오버헤드와 전송량을 최소화합니다.
  * API 응답 상의 `original` 및 `translated` 키 값은 빈 문자열(`""`)로 치환되어 리턴됩니다.
* **`light=False` 인자 적용 시 (기본값):**
  * 이전과 동일하게 원문과 번역문을 포함한 전체 텍스트가 반환되어 기존 프론트엔드 코드(어드민 및 익스텐션)가 오동작하지 않도록 보장합니다.

## 3. 결과 및 기대효과
* 기존 웹 관리자 UI의 정상 작동을 안전하게 담보하는 동시에, 뷰어 목차(TOC) 등 메타데이터만 신속하게 로드해야 하는 화면을 구현할 때 `/translations_by_folder?light=true`를 호출하여 로딩 지연을 즉각적으로 해결할 수 있는 수단을 마련했습니다.
