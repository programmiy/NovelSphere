# [기능 개선] 뷰어 문장 롱프레스 원문 인라인 토글 & 상시 버튼 제거 (2026-11-12)

## 1. 개요 및 배경
- **문제점**: 이전 구현에서는 각 문장 하단에 `[原 원문 대조]` 및 `[🖊️ 마킹]` 버튼이 상시 노출되어 있어 본문 텍스트의 몰입감과 미관을 해쳤음. 또한 문장 롱프레스 시 모달 바텀시트가 열려 대역 대조 흐름이 끊겼음.
- **개선 목표**:
  1. 본문 문장 아래의 상시 노출 버튼 행을 전면 제거하여 전자책 본문의 순수 가독성을 100% 회복.
  2. 번역문 문장을 **길게 누르면(Long Press)** 해당 문장 바로 아래에 일본어 원문 블록이 즉시 펼쳐짐.
  3. 펼쳐진 **일본어 원문 블록을 다시 길게 누르면(Long Press)** 원문이 즉시 닫힘 (토글).
  4. 원문이 펼쳐졌을 때만 원문 블록 헤더 우측에 `[🖊️ 마킹]` 버튼과 `[⋯]` 더보기 버튼을 배치하여 원문 대조 후 원터치 마킹 및 상세 제어 지원.

---

## 2. 세부 변경 사항

### 2.1 뷰어 문장 렌더러 (`mobile_app/lib/ui/viewer/reader_screen.dart`)
- **`_onSentenceLongPressed` 메서드 개편**:
  - 기존의 모달 바텀시트 직접 호출을 걷어내고, 원문 토글 로직으로 전환.
  - 원문이 존재하는 문장인 경우 `HapticFeedback.lightImpact()` 진동과 함께 `_expandedOriginalPids` Set에 해당 `sentence.pid`를 추가/제거 토글.
  - 원문이 없는 문장(구분선 등)인 경우에만 기존 상세 시트(`_showSentenceActionSheet`)로 안전 폴백.
- **본문 상시 버튼 제거**:
  - `_buildSentenceItem` 내의 `[原 원문 대조]` / `[마킹]` 상시 노출 Row 제거.
- **원문 블록 인라인 GestureDetector 장착**:
  - 원문 블록 컨테이너에 `GestureDetector(onLongPress: ...)`를 달아, 펼쳐진 일본어 원문 텍스트를 길게 누르면 `HapticFeedback.lightImpact()`와 함께 즉시 원문이 닫히도록 구현.
  - 배경 탭 흡수(`onTap: () {}`)로 화면 상하단 바가 불필요하게 토글되는 현상 방지.
  - 원문 블록 헤더에 `[日本語 原文]` 라벨, `[🖊️ 마킹]` 원터치 버튼, `[⋯]` 더보기 아이콘(수동 키보드 수정, 복사 등)을 단정하게 정돈.
