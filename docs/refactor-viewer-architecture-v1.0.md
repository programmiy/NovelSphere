# 리팩토링: 뷰어 아키텍처 개편

## 버전

v1.0

## 변경 사항

- **성능 개선을 위한 데이터 로딩 방식 변경:**
  - 대용량의 책(폴더)에서 발생하던 초기 로딩 성능 문제를 해결하기 위해, 뷰어의 데이터 로딩 아키텍처를 전면 개편했습니다.
  - 기존의 모든 번역 기록을 한 번에 불러오는 방식 대신, 현재 보고 있는 항목만 개별적으로 불러오는 'On-demand' 방식으로 변경했습니다.
  - 페이지를 넘길 때마다 다음/이전 항목의 데이터를 실시간으로 서버에 요청하여 표시합니다.

- **목차 사이드바 기능 추가:**
  - 사용자가 책의 전체 구조를 쉽게 파악하고 원하는 위치로 바로 이동할 수 있도록 목차 사이드바 기능을 추가했습니다.
  - 헤더의 '목차' 버튼을 통해 사이드바를 열고 닫을 수 있습니다.
  - '원문 보기', '야간 모드' 등 기존 뷰어 설정 기능들을 사이드바 하단으로 이동시켰습니다.

- **백엔드 API 추가:**
  - 새로운 아키텍처를 지원하기 위해 개별 아이템 조회, 이전/다음 아이템 탐색, 목차 목록 조회를 위한 신규 API 엔드포인트를 `server.py`에 추가했습니다.

## 변경된 파일

- `server/templates/viewer.html`
