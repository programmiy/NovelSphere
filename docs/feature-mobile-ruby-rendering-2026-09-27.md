# 모바일 뷰어 번역문 루비(Ruby) 및 방점(傍点) 자동 렌더링 기능 구현 (2026-09-27)

## 1. 개요
- **목적**: 라이트노벨 번역문 내에 포함된 방점 표기(`글(・)`) 및 루비 표기(`단어《루비》`, `|단어《루비》`)를 자동 감지하여 출판사 문고본 스타일의 상단 첨자 텍스트로 시각화.
- **적용 대상**: Flutter 모바일 리더기(`mobile_app/lib/ui/viewer/`)의 번역문 렌더링 엔진.

---

## 2. 세부 구현 내용

### 2-1. `NovelRubyText` 및 `NovelRubyParser` 구현 (`novel_ruby_text.dart`)
- **초고속 O(1) 필터링**:
  - `hasRubyOrBouten`: 문자열에 `・` 또는 `《`가 포함되지 않은 대다수(95% 이상)의 일반 문장은 파싱 과정을 건너뛰고 기존 `Text` 위젯으로 즉시 고속 렌더링.
- **방점(傍点, Bouten) 감지 & 렌더링**:
  - 정규식: `([^\s(（])\s*[（(]・[）)](\s*)`
  - 예시: `악(・)인(・)` $\rightarrow$ '악', '인' 글자 상단 중앙에 볼드 점(`・`)을 각각 배치하고 공백은 자연스럽게 유지.
- **루비(Ruby) 감지 & 렌더링**:
  - 정규식: `([|｜]?[가-힣a-zA-Z0-9_]+)《([^》]+)》`
  - 예시: `사정《나카다시》`, `빙탄환《아이스 불릿》`, `|초전자포《레일건》`
  - 본문 단어 위에 본문 폰트 크기의 50% 비율로 루비 텍스트를 상단에 배치하고 `WidgetSpan`으로 인라인 줄바꿈 흐름에 결합.
  - 단독 괄호(예: `《코우미》『대사』`)는 루비로 오인되지 않고 정상 텍스트로 보존.

### 2-2. `ReaderScreen` 문장 렌더러 연동 (`reader_screen.dart`)
- `_buildSentenceItem` 내의 한국어 번역문 위젯을 기존 `Text(sentence.translated)`에서 `NovelRubyText(text: sentence.translated, ...)`로 교체.
- 사용자가 설정한 한국어 폰트, 글자 크기, 줄 간격(기본 1.85), 테마 색상과 완벽 연동.
