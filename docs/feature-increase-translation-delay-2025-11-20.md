# 번역 배치 대기 시간 증가 (2025-11-20)

## 변경 사항
`extension/content.js` 파일에서 번역 배치 처리 시 다음 두 가지 대기 시간을 증가시켰습니다.
- 일반 텍스트 묶음 간 대기 시간: 60초에서 90초로 증가.
- 긴 텍스트 개별 처리 간 대기 시간: 10초에서 15초로 증가.

## 변경 이유
Gemini API의 RPM(Requests Per Minute) 제한으로 인해 과도한 요청이 발생하여 429 오류가 발생하는 것을 방지하고, 번역 작업의 안정성을 높이기 위함입니다. 대기 시간 증가를 통해 API 호출 빈도를 낮추어 오류 발생 가능성을 줄이고, 번역 프로세스의 성공률을 개선합니다.
