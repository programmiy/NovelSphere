# LANOVEL 모바일 완전 독립 서재 앱 (LANOVEL Reader)

기존 PC 서버 및 모바일 웹 서재(`library_mobile.html`, `viewer.html`)에 일체 의존하지 않고, 비행기 모드나 완전 오프라인 환경에서도 23만 문장의 모든 소설을 1ms 만에 열람할 수 있는 **Flutter 기반의 독립 전자책 리더 앱**입니다.

---

## 🌟 주요 기능 및 설계

### 1. 계층형 하이브리드 압축 SQLite 저장소 (`LocalDbService`)
- **초고속 서재 목록 렌더링**: 메타데이터(책 목록, 챕터 목록, 북마크, 진도)는 압축하지 않은 일반 인덱스 컬럼으로 관리하여 0초 만에 화면이 로딩됩니다.
- **챕터 단위 zlib 압축 BLOB**: 23만 7천 건의 전체 번역 문장을 챕터 단위로 압축하여 저장하므로, 앱 전체 DB 크기가 **약 25~35MB**로 압축됩니다.
- **체감 렉 0% (Zero-lag)**: 챕터를 누르는 순간 해당 1행의 15KB 압축 BLOB만 메모리에서 1ms 만에 압축 해제합니다.

### 2. 기성 전자책 앱(리디, 문피아) 동급의 뷰어 (`ReaderScreen`)
- **3분할 탭 네비게이션**: 화면 좌 25%(이전 페이지), 우 25%(다음 페이지), 중앙 50%(헤더/푸터 컨트롤 바 표시/숨김).
- **듀얼 뷰 모드**: 정밀 페이지 넘김 모드 (Paging) & 연속 스크롤 모드 (Scroll).
- **12종 세분화 감성 테마**: 웜 페이퍼, 내추럴 크림, 퓨어 화이트, 빈티지 세피아, 소프트 민트, 로즈 밀크, 라벤더, 슬레이트 블루, 모던 차콜, 미드나이트 네이비, 다크 모카, OLED 퓨어 블랙.
- **언어별 독립 폰트 설정**: 한국어 번역문 폰트(KoPub바탕, 나눔명조, 프리텐다드 등)와 일본어 원문 폰트(Noto Serif JP, Noto Sans JP, Shippori Mincho 등)를 각각 분리하여 지정 가능.
- **뷰어 내 롱프레스 즉시 오역 수정**: 문장을 길게 누르면 바로 수정 팝업이 뜨고, 수정 즉시 해당 챕터 BLOB이 재압축 저장되며 오프라인 큐에 자동 적재.
- **볼륨키 페이지 넘김 & 화면 켜짐 유지(Wakelock)** 지원.

### 3. 신뢰 Wi-Fi 2개 환경 기반 스마트 동기화 (`SyncService`)
- 사용자가 앱 내에서 등록한 **최대 2개의 신뢰 Wi-Fi**(예: 집 Wi-Fi, 작업실 Wi-Fi)에 연결되어 있을 때에만 동기화 기능이 활성화되어 배터리와 모바일 데이터를 보호합니다.
- **PC $\rightarrow$ 앱 (Full Seed)**: 최초 1회 23만 건의 최적화 압축 패키지(약 26MB)를 1~2초 만에 다운로드하며, 전송 완료 확인 즉시 PC 서버의 임시 파일이 자동 삭제됩니다.
- **앱 $\rightarrow$ PC (Push)**: 오프라인에서 편집한 번역문, 독서 진도, 찾아바꾸기 룰을 Gzip 압축 JSON으로 PC 서버에 전송하여 DB에 일괄 Upsert 반영.
- **PC $\rightarrow$ 앱 (Pull)**: PC에서 새로 번역/추가된 문장 및 활동 정보만 증분 다운로드.

### 4. PC 관리자급 오프라인 "일괄 찾아바꾸기" (`GlossaryScreen`)
- 소설 범위(전체 소설 또는 특정 책), 찾을 단어, 바꿀 단어, 정규표현식, 대소문자 구분 옵션 지원.
- 오프라인 상태에서 수천 개의 문장을 순식간에 치환하고, 해당 규칙이 동기화 큐에 등록되어 PC 서버 연결 시 서버 DB에도 영구 반영됩니다.

### 5. PC 생성 압축 TTS 오디오 플레이어 (`TtsAudioService`)
- PC 서버에서 고품질로 생성된 챕터별 TTS 오디오 파일(`.mp3`)을 압축 스트리밍으로 다운로드하여 로컬에 캐싱.
- 화면이 꺼진 상태에서도 블루투스 이어폰으로 백그라운드 재생, 배속 조절(0.8x ~ 2.0x), 10초 탐색 지원.

### 6. 독서 잔디 심기 & 통계 (`ReadingStatsSheet`)
- 깃허브 잔디처럼 최근 12주간의 일별 독서량(페이지/시간) 히트맵 캘린더 시각화.

## 🚀 실행 및 빌드 방법

### 1. Flutter 설치 (D 드라이브 자동 설치)
```powershell
.\scripts\setup_mobile.ps1 -InstallFlutter
```

### 2. PC 크롬 브라우저에서 모바일 앱 테스트
```powershell
.\scripts\setup_mobile.ps1 -RunWeb
```

### 3. 스마트폰 설치용 안드로이드 릴리스 APK 빌드
```powershell
.\scripts\setup_mobile.ps1 -BuildApk
```
빌드 완료 후 `mobile_app/build/app/outputs/flutter-apk/app-release.apk` 파일을 스마트폰으로 복사하여 설치하시면 됩니다.
